# T-ASE manuscript: "Who Backs Up?"

LaTeX source of the IEEE T-ASE submission "Who Backs Up? Benchmarking Decentralized
Multi-Robot Yield Negotiation in Narrow Corridors" (George, Glavin, Jones, Deegan),
revised after the internal referee review. `paper/` is the older RA-L draft.

Numbers come from the frozen WP1 code (`studies/results_raw/COMMIT`) and the WP2–WP8
reports in `studies/report_r2/`.

Build:

```
latexmk -pdf main.tex
```
